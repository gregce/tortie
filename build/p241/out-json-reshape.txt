         (without the guard it would have written: { "2": "b", "10": "a", "k": "c" })
refuses  duplicate keys                 re-serialising would change more than whitespace at offset 5: "1,\"a\":2}" would become "2}"
         (without the guard it would have written: { "a": 2 })
refuses  integer past 2^53              re-serialising would change more than whitespace at offset 23: "890}" would become "000}"
         (without the guard it would have written: { "id": 12345678901234567000 })
refuses  decimal past a double          re-serialising would change more than whitespace at offset 23: "789}" would become "8}"
         (without the guard it would have written: { "x": 0.12345678901234568 })
refuses  negative zero                  re-serialising would change more than whitespace at offset 5: "-0}" would become "0}"
         (without the guard it would have written: { "x": 0 })
refuses  exponent out of range          re-serialising would change more than whitespace at offset 5: "1e400}" would become "null}"
         (without the guard it would have written: { "x": null })
