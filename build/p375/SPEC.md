## 1. The answer first

The script Phase 374 generates already finds the top level `email` and hashes it. It now ALSO writes it, as `"e"`, in
the one line it already writes, when the raw JSON token is a plain ASCII address (no escape of any kind, one `@`, a dot
after it, at most 64 before it and 254 in all); otherwise `"e":null`. Nothing needs escaping, because nothing that would
need it is kept. Every other byte it writes is the parent's. Main reads `e` back through one shared check,
`usageAddress`, and puts it on the Antigravity row as an optional `email` only that row ever carries. The card draws
`Login: <address>` from it exactly where Claude's and Codex's login line goes, with no Choose login. Settings then Agents,
Logins draws one read-only line, `<address> · Signed in to the Antigravity CLI. Switch accounts there.`, read through a
new channel that answers what main already holds and starts nothing.
