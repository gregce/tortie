# Changelog

Each release lists its changes under Added, Changed and Fixed. Two rules keep the sections readable, and both exist because the operator asked for them on 2026-08-16. First, every commit appears in EXACTLY ONE section, chosen by what the commit is: new capability under Added, a repaired defect under Fixed, existing behavior reshaped under Changed. One commit gets one item that tells its whole story, never one item per section, because the same hash repeated across three headers is confusing and defeats the point. Second, every paragraph and every bullet sits on a single unwrapped line, because the GitHub release page renders a newline as a line break, and hard-wrapped text shows ragged there. Prose appears above the sections only when something needs explaining. Versions follow semver: the minor moves for features, the patch for fixes. Release pages carry these entries verbatim.

## 0.68.7 (2026-08-23)

A folder on another machine is no longer read only. You can open a file over there, type into it and press Command S, and the bytes land on that machine. You can make a new file, make a folder and rename what is already there. You can choose what goes into the next commit, type a message and commit, from the Changes list you are already looking at. None of it is on by default. In Settings then Machines you name the one folder on that machine Tortie may write under, and you confirm a sheet that says in plain words what Tortie will then be able to do. A machine you set up before this release carries no such folder, so its agreement is unchanged and nobody is asked to confirm anything again. Nothing here was proved against a second Mac or against any Linux machine, and every number in this release was measured against a stand-in machine running on this same Mac.

The application window got several things you asked for by name. Project tabs can collapse where they are, and they can be a rail down the left side. The session list answers the arrow keys. Settings then Agents is a row of pages instead of one long scroll. The panel that installs a skill keeps its Install button on screen at every height, which is the button you reported you could not find. The machine row in Settings opens with whether the machine is ready, rather than reaching it after five paragraphs of qualification. The empty column beside the sidebar is gone while the projects are on the left, and the work area gets 48px back.

The largest part of this release by volume is work you cannot see. Two of the biggest files in the tree were broken into smaller ones. Six loops in which of Tortie's own files loads which were cut. The test harness code left the load an ordinary launch reads. The description Tortie keeps of its own internal bridge stopped saying that 93 of its members might be missing. Each of those landed with a new check that runs inside typecheck, build or package, so the next change that breaks the same thing fails before it ships rather than after it reaches you. No value you can read on screen moved for any of it.

## 0.18.0 (2026-08-14)

The first release you can download and install. Tortie is a macOS home for coding agents: your projects open as tabs in one window, you start Claude Code, Codex, Cursor or any of twelve supported agents with a keystroke, and the work keeps running whether the window is open or not. Quit the app, reboot the Mac, come back tomorrow, and your sessions are still there with their scrollback and a resume command ready for the agent's own conversation.

The build is signed with a Developer ID and notarized, so it opens without the right-click ritual an unsigned app needs. If you ran an earlier build, macOS asks once more for each permission you had granted, because the app's identity changed to `com.itavero.tortie` and macOS ties permissions to identity. Your data and your sessions are not touched.

Two limits worth knowing. This build does not update itself, so an update is a download and a drag until 0.19.0. And once it has opened your session data, older builds refuse to open it, which is deliberate and one way only.
