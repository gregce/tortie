The control. This is Tortie's chrome as it is today, on 2026-09-01. Nothing in it is proposed and nothing is improved. Every colour is a token read out of tokens.css, every height and padding is read out of the stylesheet that draws that region, and the icons are drawn on the codicon font's own 16px grid at the five sizes the app actually asks for, so their weights differ here exactly as much as they differ on screen. Judge the three options against this frame rather than against memory. Where an option looks better, it has to be better than what is here; where this frame is already right, an option that changes it is a regression.
