# Tortie cool icon with contour line work

`tortie-cool-linework.png` is a transparent 1024×1024 evolution of the cool
illustrated Tortie icon.

The edit preserves the silhouette, five scutes, palette, painted fields,
shading and grain. It adds restrained contour strokes that follow each scute's
curvature:

- deep blue-gray lines on pale regions
- muted light-blue lines on dark regions
- rounded ends and gently varying weight
- selective pale-blue echo lines beside existing contours

The line work is intentionally secondary. It adds shell anatomy and continuity
at Dock and marketing sizes, then recedes at 32px so the five-field silhouette
still carries the icon.

The built-in GPT Image workflow performed the edit. A flat chroma-key
background was removed locally; the result was validated at 1024×1024 with an
alpha channel and reduced to 32px for a legibility check.
