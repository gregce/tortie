# Tortie minimalist Dock-icon exploration

These transparent 1024×1024 PNGs restart the shell as a minimal app mark. The
reference was the visual discipline of a macOS Dock: one dominant silhouette,
two or three values, smooth geometry and immediate recognition at small sizes.
No visible reference logo was copied.

1. `01-three-cut-shell.png` — one dark shell with blue seams and a pale-blue
   corner. Bold, but can read as a capsule.
2. `02-folded-shelter.png` — three forms around an ice centre. Compact and
   ownable, but more abstract than shell-like.
3. `03-quiet-shell-glyph.png` — dark carapace divided by one pale-blue branching
   path. The clearest shell and strongest Dock-scale result.
4. `04-blue-scute.png` — four colour fields inside a dark silhouette. The
   simplest conventional app mark, but less uniquely Tortie.

## Shared constraints

- free-standing shell with no surrounding squircle, tile or app chrome
- maximum four meaningful shapes and three colours
- graphite, app blue, light blue and ice only
- no texture, brush fields, decorative line work or realistic material
- no head, limbs, face, eyes, mascot features, text or terminal glyph
- designed and checked at 64px Dock scale

The built-in GPT Image workflow generated each direction against a flat chroma
key, using the supplied Dock screenshot as a style-discipline reference only.
The backgrounds were removed locally and each PNG was validated at 1024×1024
with alpha.
