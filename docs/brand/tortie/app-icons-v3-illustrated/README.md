# Tortie illustrated icon exploration

These are illustrated, free-standing 1024×1024 PNG logo concepts with
transparent backgrounds. They preserve the second exploration's shell forms
but replace realistic material rendering with smooth contours, confident
strokes and broad colour shapes.

1. `01-river-shell-illustrated.png` — quiet neutral shell with four flowing
   regions. Understated and calm.
2. `02-tortoiseshell-illustrated.png` — five warm tortoiseshell fields. The
   most distinctive, name-specific and logo-like direction.
3. `03-shelter-illustrated.png` — four graphite forms protecting a terracotta
   centre. The cleanest expression of the Zen of Tortie.
4. `04-continuity-shell-illustrated.png` — a warm path held within a low shell.
   The most explicit continuity metaphor, with the greatest visual detail.

## Shared visual language

- smooth, authored curves and rounded joins
- consistent dark outer contour and deliberate internal strokes
- broad flat fills with restrained two-step shading
- subtle print grain rather than photoreal surface texture
- serious independent-software character, without mascot features
- no background tile, app chrome, badge, text or terminal glyph

The built-in GPT Image workflow used each v2 PNG as an edit target and
structural reference. It changed the rendering language while preserving the
shell silhouette and palette. The generated chroma-key backgrounds were
removed locally, and each final PNG was validated at 1024×1024 with alpha.
