# Tortie cool illustrated icon

`tortie-cool.png` is a transparent 1024×1024 recolour of the selected
tortoiseshell illustration. Its silhouette, five-panel construction, brush
shapes, smooth strokes, shading and grain are preserved.

The palette comes from the application:

- ink and outline: `#0d1117`
- graphite: `#131417`, `#1b1d22`, `#2a2e36`, `#3a3e48`
- primary blue: `#4d9de8`
- light blue: `#82bfff`
- ice highlight: `#c7e4ff`
- blue-gray: `#6e8eaa`

All orange, amber, red, brown, bronze, yellow and cream were removed. The
result remains mostly dark graphite, with one clear blue field and one pale
blue field carrying the recognisable tortoiseshell contrast.

The built-in GPT Image workflow performed a colour-only edit against the v3
illustrated PNG. A flat chroma-key background was removed locally; the final
file was validated at 1024×1024 with alpha and visually checked over light and
dark surfaces.
