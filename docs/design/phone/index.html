Tortie for iPhone

A remote control for the Tortie client on your Mac — not a terminal. Seven screens. Every word on them is a string Tortie already says, taken from the module that owns it; five phrases are new and marked as such in the spec. Colour is spent on state and nothing else: the amber dot is the loudest object on every screen and the only thing that pulses.

Scroll sideways for all seven. Tap the first row of screen 1 to walk list → session → composer; screen 3b's hand-off goes back to the session. Grounds are Tortie's own surround #0E0F13 with cards at #191B20 — never the work's #131417, because the phone is the frame around the Mac's work rather than the work itself.
